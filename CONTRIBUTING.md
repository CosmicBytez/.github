# Contributing to CosmicBytez Projects

Thanks for your interest in contributing! These guidelines apply to all public repositories in the [CosmicBytez](https://github.com/CosmicBytez) organization.

## Reporting Bugs

- Search existing issues first to avoid duplicates.
- Use the bug report template and include your OS, app/tool version, and steps to reproduce.
- For **security vulnerabilities**, do **not** open a public issue — see [SECURITY.md](SECURITY.md).

## Suggesting Features

Open a feature request issue describing the problem you're trying to solve, not just the proposed solution. Context about your use case helps us prioritize.

## Pull Requests

1. Fork the repository and create a branch from `main`.
2. Keep changes focused — one logical change per PR.
3. Follow the existing code style of the project.
4. Use [Conventional Commits](https://www.conventionalcommits.org/) for commit messages, e.g.:
   - `fix: correct container status polling on Windows`
   - `feat: add CSV export to latency report`
   - `docs: clarify installation prerequisites`
5. Make sure the project builds and existing tests pass before submitting.
6. Reference any related issues in the PR description (e.g. `Fixes #12`).

Small fixes (typos, docs) are welcome without prior discussion. For larger changes, please open an issue first so we can align on the approach before you invest time.

## Code of Conduct

By participating, you agree to abide by our [Code of Conduct](CODE_OF_CONDUCT.md).
